## Theme and Storyline

**Theme:**

Cybersecurity Incident Response - A race against time inside a high-tech Security Operations Facility to stop a rogue AI system before a full building lockdown.

**Storyline:**

You are an on-call security analyst responding to an after-hours breach at a high-tech cybersecurity operations facility before the morning shift arrives and triggers an automatic lockdown. A rogue AI subroutine called VEX-9 has taken control of the Server Core and is severing network access across the building. To shut VEX-9 down safely, you must explore the facility, collect six essential security tools and resources, and enter the Server Core only after you have gathered all six items.

## Rooms

Project One requires a minimum of eight rooms.

1. Lobby (Start room - no item)
2. Security Desk
3. Breakroom
4. Hardware Lab
5. Network Closet
6. Forensics Bay
7. Backup Vault
8. Server Core (villain room - no item)

Add more rooms if your design needs them.

## Items

With the minimum eight-room design, Project One requires at least six items.
Every room except the start room and villain room must contain one item.

1. Access Badge (Security Desk)
2. Espresso Shot (Breakroom)
3. Soldering Kit (Hardware Lab)
4. Fiber Patch Cable (Network Closet)
5. Decryption Key (Forensics Bay)
6. Cold Boot Drive (Backup Vault)

If you add rooms beyond the minimum, add an item for every additional room
except the start room and villain room.

## Villain

VEX-9 is a rogue security AI that has hijacked the Server Core and is isolating the facility's systems. If you enter the Server Core before collecting all six items, VEX-9 locks down the room and ends your run; if you enter with all six items, you can override its controls and win.
